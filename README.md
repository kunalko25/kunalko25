# 🚀 Featured Projects

### 🔐 1. Phishing Email Detector

<a href="https://github.com/kunalko25/Phishing-Email-Detector">
<img src="https://img.shields.io/badge/VIEW_PROJECT-00ff41?style=for-the-badge&logo=github&logoColor=black" alt="View Project">
</a>

An interactive phishing email detection project designed to analyze email content, identify suspicious patterns, and help users understand email-based cyber threats.

**✨ Key Features**

- 🔍 Advanced keyword and phishing pattern detection
- 🌐 Suspicious URL and IP-based URL detection
- 🔗 Shortened URL detection
- ⚠️ Suspicious domain detection
- 🏢 Brand impersonation detection
- 🔐 Sensitive information request detection
- 📊 Threat scoring with Safe, Suspicious, and Phishing classifications
- ⚡ Real-time threat scoring while typing
- 📄 PDF report export and copy analysis report
- 📚 Interactive phishing awareness quiz
- 🏆 Achievement and progress tracking
- 📈 Analysis history and statistics dashboard
- 🌙 Dark and Light mode

**🛠️ Technologies & Concepts**

- React
- JavaScript
- HTML5
- CSS3
- LocalStorage
- Email Security
- Phishing Detection

**🎯 Project Goal**

To help users recognize suspicious emails, understand phishing techniques, and improve their cybersecurity awareness.

🔗 **Repository:** [Phishing-Email-Detector](https://github.com/kunalko25/Phishing-Email-Detector)
